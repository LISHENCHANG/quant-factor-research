# 数据契约

本目录只保留说明文件。请自行准备行情数据，并命名为：

```text
stocks_daily_04-25.parquet
```

## 必需字段

| 字段 | 含义与要求 |
|---|---|
| `股票代码` | 字符串；支持 `.SH`、`.SZ`、`.BJ` 后缀 |
| `股票名称` | 字符串；用于 ST 过滤 |
| `交易日` | 可转换为 `YYYYMMDD` 整数日期 |
| `开盘价` | 正数 |
| `最高价` | 正数，且满足正常 OHLC 关系 |
| `最低价` | 正数，且满足正常 OHLC 关系 |
| `收盘价` | 正数 |
| `成交量（手）` | 非负；1 手按 100 股换算 |
| `成交额（千元）` | 非负；计算 VWAP 时转换为元 |
| `换手率（%）` | 非负百分比数值 |
| `总市值（万元）` | 正数；用于规模中性化 |
| `复权因子` | 正数；用于复权价格/VWAP |

## 数据边界

- 主研究需要 2004–2021 年数据：2004–2005 用于滚动预热，2006–2017 为训练集，2018–2021 为验证集。
- 2022 年及以后应作为最终测试集保留，不要在研究参数冻结前查看。
- 每个交易日建议至少包含 100 只有效股票，否则会被视为异常交易日。
